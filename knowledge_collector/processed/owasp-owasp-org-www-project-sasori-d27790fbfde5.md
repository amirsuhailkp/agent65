# OWASP Sasori

- Sasori is dynamic web crawler which uses a browser to find links, forms and other actions on a webpage and interacts with them in human like manner.
- Sasori aims to be the best open source dynamic web crawler in the world.
- Sasori aims to solve problems that other dynamic web crawlers don’t.
- Sasori has seamless authentication support so that it can crawl web applications behind authentication as well.
- It should easily crawl SPAs.

### Road Map

A stable version is already available here: [https://github.com/karthikuj/sasori|https://github.com/karthikuj/sasori]

- There will be more bug fixes and patches down the road.
- New features like BFS, DFS support will be introduced.
- Stealth features will be added to avoid bot detection.
